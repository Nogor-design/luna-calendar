# Luna

A simple, responsive lunar calendar for tracking daily moon phases and notable sky events.

## Features

- Approximate daily lunar phases and illumination
- Interactive month navigation
- Clickable dates with moon and cosmic-event details
- Upcoming major moon phases
- Curated 2026–2027 eclipse and meteor-shower dates from NASA
- Responsive, accessible one-page design

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
```

Lunar phase values are astronomical estimates. Event visibility varies by location and local conditions.
